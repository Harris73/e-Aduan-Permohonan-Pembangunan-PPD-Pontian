Panduan Pelaksanaan Live Web 24/7 (VS Code + Cloud Hosting)

Mengapa laman web boleh berfungsi 24/7 walaupun PC dipadamkan?

Kod website yang dibina di dalam **VS Code** anda akan dimasukkan ke pelayan awan (**Cloud Server**) percuma seperti **Vercel** atau **Netlify**. Pelayan awan ini beroperasi 24 jam sehari di pusat data global. Database & simpanan fail fail PDF/Gambar pula disimpan di **Firebase** atau **Supabase**.

Langkah demi Langkah (Step-by-Step Implementation)

1
Sediakan Kod dalam VS Code & Muat Naik ke GitHub

1. Simpan kod `index.html` ini di dalam folder projek di VS Code.
2. Buka Terminal dalam VS Code dan jalankan arahan git:

git init
git add .
git commit -m "e-Aduan PPD Pontian Initial Commit"
git push origin main
2
Sambungkan GitHub ke Vercel / Netlify (Free Hosting 24/7)

1. Layari **Vercel.com** atau **Netlify.com** dan daftar secara percuma menggunakan akaun GitHub.
2. Pilih **"Add New Project"** -> Pilih Repository GitHub anda.
3. Klik **"Deploy"**. Dalam tempoh 1 minit, anda akan mendapat pautan rasmi unik (Contoh: `https://e-aduan-ppdpontian.vercel.app`).

3
Sambungkan Firebase / Supabase (Database Realtime & Storage PDF/Gambar)

Untuk menyimpan aduan, fail PDF surat rasmi, dan bukti gambar kekal tanpa hilang:

  • Auth: Memastikan hanya Guru Besar & Pegawai PPD disahkan sahaja boleh akses.
  • Firestore / Database: Menyimpan senarai aduan, masa hantar, dan status FIFO.
  • Storage: Tempat penyimpanan fail gambar bukti dan PDF rasmi.
Perkongsian Pautan (Shared Link)

Pautan domain dari Vercel boleh dikongsi terus melalui WhatsApp atau QR Code kepada semua Guru Besar di daerah Pontian dan boleh dibuka di mana-mana smartphone mahupun PC tanpa sebarang masalah compatibility.
